# Footage-first openings

Use this when asked to choose an opening from footage, or when the user supplies media for a video hook, script, edit, or audit. Select the story and opening from the strongest usable evidence for the viewer and goal. A copy-only request still gets copy only. Read the [project brand voice card](project-brand-voice.md) when one is available for this brand.

## Inspect the material before drafting

1. **Identify available media.** Use the attached or explicitly scoped project clips and stills. Identify each by filename or supplied label. Inspect the candidate moment, enough surrounding material to establish what happened, and the proof needed for the first body beat. Sample frames when that is what the host supports. Read duration, orientation, and audio presence when relevant, and distinguish these metadata checks from seeing motion or hearing sound.
2. **Record the source and evidence.** For video, use source time relative to that clip. If you reviewed motion, give an appropriate in and out. If you saw sampled frames, identify the sampled time or range to review and label start/end points as candidate trims. For a still, use the asset and visible region. State what the source actually shows and the limit that matters to the hook. Treat source audio and picture separately when only one was inspected. Use program time for the resulting edit only when useful, and label it separately.
3. **Compare usable moments.** Favor a relevant action, visible result, or readable clue with a useful next beat. A clear quiet shot may do the job. Start immediately before the meaningful change if the viewer needs context. A still can show a condition or a labeled comparison. A process shot can demonstrate the step it contains. A before/after needs the relevant states and context, and a causal claim needs evidence of the mechanism or a properly supported comparison.
4. **Select and connect.** Match the opening to a concrete brand cue and a supported body payoff. Name the source moment, crop or hold, actual spoken or on-screen line, and the exact next shot or action. With silent edits, test whether the image and exact overlay make sense together. Allow enough reading time and keep important content visible in the intended crop. If options are requested, give distinct treatments the available media supports and recommend one. If the user asks for a full script, include the selected opening and continue into it.

## Distinguish evidence from a capture plan

| Material status | What to deliver |
|---|---|
| Inspected clip or still | Give a verified source locator at the precision the inspection supports. Identify anything material still to preview, such as the exact cut or audio mix |
| User description, frame labels, or transcript only | Cite what was supplied, label it as described, and identify the moment by its action. Use any user-supplied time with that attribution. Ask for a timecode or clip only when it would change the choice |
| Media inaccessible or missing | State the access limit briefly. Offer a conditional opening from the stated material or a separately labeled capture plan. Give an exact trim after the clip or its locator can be checked |

A filename, duration, waveform, or transcript alone is insufficient to establish a visual. A result still alone supports what is visible in that still. Keep reconstructions, placeholders, and requested new filming separately labeled. Use the [essential-shot checks](video-production.md#voice-and-essential-shot-feasibility) when a required shot needs a fallback.

## Compact handoff

Use the fields that fit the requested deliverable: **source** (asset and clip time, still region, or described action), **evidence** (what is visible/audible and material limits), **opening** (crop/hold, exact speech/text, sound if useful), and **next cut** (asset or action and the first value it delivers). For a menu add one short fit reason and a recommendation. Leave the choice with the user if they asked to select before drafting.
